## 🔭 What I work on
- 🤖 **Agentic AI systems**: MCP tool execution, LangGraph orchestration, and RL-trained agents (hierarchical RL, PPO, RLHF) for long-horizon, multi-step task automation
- 🔎 **Retrieval, search, and ranking**: hybrid dense + late-interaction retrieval (BGE, ColBERT, ColPali), Reciprocal Rank Fusion, cross-encoder reranking, and LTR (LambdaMART)
- 📊 **Recommender systems at scale**: Two-Tower retrieval, MMoE ranking, FAISS hard-negative mining, and cold-start recommendations across 50M+ transaction datasets
- 🧠 **GenAI & LLMs**: RAG pipelines, GraphRAG over knowledge graphs, LLM fine-tuning (DPO/QLoRA), Query Rewriting (HyDE) and LLM-as-a-judge evaluation frameworks
- ⚡ **Production ML engineering**: LLM serving (vLLM, quantization, TensorRT-LLM), MLOps (Docker, Kubernetes, MLflow, Airflow), and multi-cloud deployment (AWS, GCP, Azure)
